# Anqah Tech: Instagram launch set

Images are in `out/` (1080×1350, 4:5). Edit `posts.html` and re-render with:
`node tools/instagram/render_posts.mjs <path-to-node_modules-with-playwright-core>`

**Order:** Post 01 first and 09 last. Instagram shows the newest post first, so after nine posts your grid reads 09 08 07 / 06 05 04 / 03 02 01.
**Pace:** 3 posts a week (e.g. Mon / Wed / Sat), around 7–9 pm Gulf time. Don't post all nine on one day.
**Uploading:** in the Crop step, tap the crop icon (bottom-left) and choose **4:5**. The default is a 1:1 square, which cuts off the top and bottom. Upload each post on its own. Only the 7 `07-carousel-*` slides go together in one post.
**Hashtags:** use 3–5 relevant ones. Instagram now caps a post at 5 hashtags.
