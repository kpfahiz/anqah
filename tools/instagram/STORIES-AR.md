# Anqah Tech: قوالب الستوري (النسخة العربية)

النسخة العربية من STORIES.md. كل الصور بمقاس 1080×1920 وموجودة في مجلد `out/`. المصدر: `stories.html`، ولإعادة التصدير شغّل `render_posts.mjs`.
أزرار إنستغرام تغطي أعلى الشاشة (حوالي 250 بكسل) وأسفلها (حوالي 340 بكسل)، لذلك محتوى كل قالب في المنطقة بينهما.

## 1 · خلفيات مشاركة المنشورات (`story-share-*.png`، 17 صورة)
خلفية لكل منشور بألوانه، وسؤال التصويت الخاص به مطبوع عليها مسبقًا.

**طريقة الاستخدام (يوم النشر، بعد نشر المنشور مباشرة):**
1. افتح المنشور الجديد واضغط **✈️ مشاركة ← إضافة إلى القصة**.
2. اضغط **أداة اختيار الخلفية** في الأعلى، واختر **ألبوم الكاميرا**، ثم اختر صورة `story-share-…png` المطابقة.
   *أو ابدأ ستوري من صورة الخلفية، ثم أضف المنشور عبر **الملصقات ← منشور**، إن ظهر هذا الخيار في تطبيقك.*
3. صغّر ملصق المنشور بإصبعين حتى يناسب المربع الفارغ.
4. أضف **ملصق تصويت** تحت السؤال المطبوع:
   - خيارات قصيرة مثل «نعم 👍 / ليس بعد». السؤال مطبوع بالعربية والإنجليزية، فيفهمه الجميع.
5. أضف **ملصق موقع** (نفس مدينة المنشور)، و**ملصق رابط** إلى anqah.com إن رغبت.

| المنشور | الخلفية |
|---|---|
| 01 مرحبًا … 09 تواصل معنا | `story-share-01-hello` … `story-share-09-contact` |
| تصميم المواقع … الحلول الهندسية | `story-share-s1-web-design` … `story-share-s8-engineering` |

## 2 · قوالب قابلة لإعادة الاستخدام (`story-tpl-*.png`، 7 صور)

| القالب | متى تستخدمه | ماذا تضيف في إنستغرام |
|---|---|---|
| `story-tpl-poll` | أسئلة «هذا أم ذاك» السريعة («بطاقة أم نقدًا؟»، «موقع أم تطبيق أولًا؟») | ملصق نص بالسؤال + ملصق **تصويت** |
| `story-tpl-ask-us` | جلسة أسئلة وأجوبة أسبوعية، كل خميس | ملصق **أسئلة** فوق المربع الفارغ، ثم أجب عن كل سؤال في ستوري جديدة |
| `story-tpl-tech-tip` | نصيحة أسبوعية («انسخ بيانات الكاشير احتياطيًا يوميًا») | اكتب النصيحة فوق مربع الكود |
| `story-tpl-install-done` | كل عمل يكتمل | صورة التركيب فوق المربع الأسود + ملصق **موقع**، ومنشن العميل إن وافق |
| `story-tpl-client-review` | لقطات أو اقتباسات من عملاء سعداء | نص التقييم + اسم العميل (بإذنه) |
| `story-tpl-before-after` | ترقيات الكاميرات أو الشبكات أو المواقع | صورتان: القديم في الأعلى والجديد في الأسفل |
| `story-tpl-free-demo` | جاهز للنشر كما هو، مرة أسبوعيًا تقريبًا | ملصق **رابط** إلى الواتساب أو anqah.com |

## 3 · أغلفة الهايلايت (`story-hl-*.png`، 7 صور)
**SELLO 🧾 · الجرس 🔔 · المياه 💧 · الخدمات 🛠️ · التركيبات 📸 · العملاء ⭐ · تواصل معنا 📲**

**طريقة إنشاء كل هايلايت:**
1. الملف الشخصي ← **+ جديد** ← اختر الستوريات التي تريد ضمّها.
2. اكتب الاسم، مثل «SELLO» أو «التركيب».
3. **تعديل الغلاف** ← اختر صورة `story-hl-…png` المطابقة. إنستغرام يعرض الدائرة في المنتصف.

**الترتيب المقترح في الملف الشخصي:** تواصل معنا · SELLO · الخدمات · التركيبات · العملاء · الجرس · المياه

## إيقاع الستوري الأسبوعي (1–3 ستوري يوميًا)

| اليوم | الستوري |
|---|---|
| أيام النشر | خلفية المشاركة + تصويت (انظر TIMELINE.md و SERVICES-PLAN.md) |
| الأحد | نصيحة تقنية |
| الاثنين | تم التركيب / كواليس العمل |
| الثلاثاء | تصويت سريع |
| الأربعاء | قبل / بعد |
| الخميس | اسألنا أي شيء |
| الجمعة | تقييم عميل |
| السبت | عرض تجريبي مجاني |

- **الردود:** رُد برسالة خاصة على كل من صوّت أو أرسل سؤالًا، فكل واحد منهم عميل محتمل مهتم.
- **الهايلايت:** أضف أفضل الستوريات إلى الهايلايت المناسب لتبقى في ملفك الشخصي.
- **الخصوصية:** لا تنشر اسم عميل أو صور محله أو تقييمه إلا بإذنه.
