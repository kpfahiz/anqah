# Captions: the 6 animated Reels (ready to paste)

Each Reel has two videos, so post them as **two separate Reels**:
- **English version (`-voice-en.mp4`):** post on the scheduled date, with location **Dubai or Abu Dhabi**. Use the **EN-first** caption.
- **Arabic version (`-voice-ar.mp4`):** post 3–4 days later, with location **Riyadh**. Use the **AR-first** caption.

For every Reel:
- **Hashtags:** Instagram allows **5 at most**. Each caption below has exactly 5.
- **Cover:** tap *Edit cover → Add from camera roll* and pick the `reel-NN-….png` listed for that Reel.
- **Feed and Facebook:** turn on *Also share to feed*, and turn on *Share to Facebook* if you have a Facebook page.
- **Alt text:** *Advanced settings → Accessibility → Alt text*. Paste the alt text given below.
- **Pinned comment:** post the "first comment" line yourself and pin it.
- **Replies:** reply to every keyword comment ("POS", "WEB" …) with a DM within the first hour.
